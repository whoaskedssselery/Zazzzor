# CLAUDE.md

[English (основная версия)](CLAUDE.md)

Общие правила для людей и агентов описаны в [AGENTS.md на русском](AGENTS.ru.md). При запуске Claude Code подключает [основной AGENTS.md](AGENTS.md) из [основного CLAUDE.md](CLAUDE.md).

Проект настроен с помощью `claude-workspace` и профиля **project**.

## Как пользоваться навыками

Claude Code загружает навыки из `.claude/skills/` по мере обращения. Перед работой сопоставьте предстоящее действие с их описаниями.

- **Базовые правила действуют постоянно.** Проверяйте их при каждом подходящем действии, например перед каждым коммитом и каждым ревью.
- **Применяйте все подходящие навыки.** Если изменение затрагивает и качество кода, и визуальный дизайн, выполните оба вида проверки.

## Базовые навыки

Проверяйте эти навыки при каждом соответствующем действии.

- **health-review** — Периодический аудит проекта для любого стека. Проверяет архитектуру, сопровождаемость, согласованность дизайна, безопасность типов, повторяющиеся проблемы и возможности для обучения. Даёт проверяемые, применимые рекомендации и соблюдает правила learning-guard, когда они действуют.
- **commit-discipline** — Поддерживает понятную историю Git в учебных проектах. Помогает создавать атомарные коммиты, группировать связанные изменения, писать понятные сообщения и добавлять файлы в индекс поимённо. Соблюдает правила learning-guard.
- **codegraph** — Используйте инструменты CodeGraph MCP как основной способ навигации и изучения проекта перед написанием или редактированием кода.

## Дополнительные навыки

Применяйте навык, если задача соответствует описанию.

- **impeccable** — Для проектирования, пересмотра, оценки, аудита, доработки, упрощения, повышения устойчивости и анимации интерфейсов. Охватывает сайты, лендинги, панели, интерфейсы приложений, компоненты, формы, настройки, онбординг, пустые состояния и нативные экраны iOS и Android. Помогает с UX, иерархией, компоновкой, типографикой, цветом, движением, текстом интерфейса, доступностью, адаптивностью, крайними случаями и документированием дизайн-систем (`DESIGN.md`, токены). Подходит для более выразительного или сдержанного оформления и сложных визуальных эффектов. Применяйте к задачам с пользовательским интерфейсом.
- **taste** — Отдельный инструмент со своим установщиком. [Исходный код](https://github.com/Leonxlnx/taste-skill)
- **ui-ux-pro-max** — Помощь с UI/UX для веба, мобильных и настольных приложений. Применяется при проектировании, разработке, проверке и исправлении страниц, компонентов и дизайн-систем, а также для доступности, взаимодействия, адаптивной вёрстки, типографики, цвета, графиков и реализации под конкретный стек. Локальный поиск охватывает 79 стилей (50 активных), 192 палитры и профиля обоснования, 74 пары шрифтов, 119 рекомендаций по UX, 105 иконок, 17 пресетов GSAP, 25 типов графиков и 22 стека.
- **superpowers** — Отдельный инструмент со своим установщиком. [Исходный код](https://github.com/obra/superpowers)
- **react-expert** — Для React 18+ в файлах `.jsx` и `.tsx`, Next.js App Router и проектов create-react-app. Создаёт компоненты и хуки, исследует проблемы рендеринга, переносит классовые компоненты на функции и помогает управлять состоянием. Охватывает Server Components, границы Suspense, формы с useActionState, производительность и возможности React 19.
- **api-designer** — Для проектирования REST- и GraphQL-API, спецификаций OpenAPI и архитектуры API. Охватывает модели ресурсов, версии, пагинацию и соглашения по обработке ошибок.
- **database-optimizer** — Оптимизирует запросы PostgreSQL и MySQL. Помогает исследовать медленные запросы и планы выполнения, проектировать индексы, переписывать запросы, настраивать конфигурацию и партиционирование и устранять конфликты блокировок.
- **security-reviewer** — Находит уязвимости, оценивает их серьёзность, составляет отчёты и предлагает исправления. Применяется при аудитах безопасности кода и инфраструктуры, SAST, пентестах, DevSecOps, проверках облачной безопасности и зависимостей, поиске секретов и проверках соответствия требованиям.
- **websocket-engineer** — Для систем реального времени на WebSockets или Socket.IO, двусторонних сообщений, масштабирования через Redis, отслеживания присутствия и управления комнатами.
- **fullstack-guardian** — Для полного цикла разработки веб-приложений с защитой на каждом уровне. Поддерживает аутентификацию, проверку ввода, экранирование вывода и параметризованные запросы. Охватывает полноценную реализацию функций, REST API с интерфейсом, подключение компонентов к серверу, сквозную передачу данных от БД до интерфейса и CRUD с формами. Применяется, когда одна задача объединяет клиент, сервер и безопасность, в том числе для веб-приложений, защищённых маршрутов с экранами, микросервисов, функций реального времени, архитектуры монорепозитория и выбора технологий.
- **cloud-architect** — Для облачной архитектуры, миграций, оценки стоимости и аварийного восстановления в AWS, Azure и GCP. Охватывает Well-Architected Framework, landing zone, безопасность и serverless.
- **devops-engineer** — Для Dockerfile, CI/CD, манифестов Kubernetes, Terraform и Pulumi, автоматизации развёртывания, GitOps, инструкций на случай инцидента и инструментов внутренней платформы. Применяется для контейнеризации, управления инфраструктурой как кодом и облачными платформами, автоматизации релизов и реагирования на инциденты. Охватывает конвейеры, Docker, Kubernetes, GitOps, Terraform, GitHub Actions, дежурства и разработку платформы.
- **code-reviewer** — Анализирует diff и файлы на ошибки, уязвимости (SQL-инъекции, XSS, небезопасная десериализация), проблемы качества, запросы N+1, неудачные имена и архитектурные огрехи. Выдаёт структурированные замечания в порядке приоритета. Применяется при ревью pull request, аудитах качества, поиске возможностей рефакторинга и проверках безопасности. Дополняет **security-reviewer** и **test-master** общей проверкой корректности, производительности, сопровождаемости и покрытия тестами.
- **debugging-wizard** — Разбирает сообщения об ошибках, прослеживает ход исполнения по стеку и сопоставляет журналы. Использует проверяемые гипотезы, чтобы найти и устранить первопричину. Подходит для неожиданных результатов, падений и анализа журналов.
- **test-master** — Создаёт тесты, подбирает заглушки, анализирует покрытие, проектирует тестовую архитектуру и составляет планы тестирования и отчёты о дефектах. Охватывает модульные, интеграционные и E2E-тесты, нестабильные тесты, нагрузочное тестирование с k6 или Artillery, проверки безопасности по OWASP, автоматизацию, контроль качества, раннее тестирование и сопровождение тестов.
- **feature-forge** — Проводит обсуждение требований, формулирует спецификации функций, пользовательские сценарии, функциональные требования EARS, критерии приёмки и списки работ. Применяется при описании функций, сборе требований и создании спецификаций, PRD, сценариев или матриц требований.

## Манифест рабочего пространства

Установленный профиль и версии навыков записаны в `.claude/workspace.yaml`. После получения изменений запустите `npx claude-workspace sync`, чтобы обновить навыки.
