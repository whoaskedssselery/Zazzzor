# Zazzzor для Windows

1. Откройте [официальные релизы](https://github.com/whoaskedssselery/Zazzzor/releases),
   выберите последний `desktop-vX.Y.Z` и скачайте `Zazzzor_X.Y.Z_x64-setup.exe`.
   Нужна Windows 10/11 x64. Если WebView2 отсутствует, установщик скачает его.
2. Приложение не имеет платной подписи кода. Если SmartScreen показывает
   «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Пройдите установку на русском языке. Она ставит приложение только для вашего
   пользователя и не запрашивает права администратора.
4. При первом запуске укажите адрес своего сервера Zazzzor, полученный от его
   владельца, например `https://friends.example`. Войдите в свой аккаунт.
5. Обновления проверяются при запуске и каждые шесть часов. Новая версия
   скачивается и проверяется заранее: «Да» устанавливает её и перезапускает
   приложение, «Позже» откладывает предложение до следующего запуска.
   Проверить вручную можно через трей → «Проверить обновления».
