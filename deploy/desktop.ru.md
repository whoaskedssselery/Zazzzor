# Zazzzor для Windows

[English](desktop.md) · **Русский**

1. Откройте [официальные релизы](https://github.com/whoaskedssselery/Zazzzor/releases),
   выберите последний `desktop-vX.Y.Z` и скачайте `Zazzzor_X.Y.Z_x64-setup.exe`.
   Нужна Windows 10/11 x64. Если WebView2 отсутствует, установщик скачает его.
2. У приложения нет сертификата подписи кода. Если SmartScreen показывает
   «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Выберите язык установщика. Доступны английский и русский, английский идёт
   первым. Установка выполняется для текущего пользователя и не требует прав
   администратора.
4. При первом запуске укажите адрес своего сервера Zazzzor, полученный от его
   владельца, например `https://friends.example`. Войдите в свой аккаунт.
5. Приложение проверяет обновления при запуске и каждые шесть часов. Оно заранее
   скачивает и проверяет новую версию. Нажмите «Да», чтобы установить её и
   перезапустить приложение. «Позже» откладывает предложение до следующего
   запуска. Проверить вручную можно через трей → «Проверить обновления».

Если вы настраиваете собственный сервер, см. [руководство владельца сервера](README.ru.md).
